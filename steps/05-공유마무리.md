# 05 · 공유와 마무리

**목표**: 결과를 공유하고 수업 후 이어서 할 일을 남긴다.

## 결과 정리

- 해결하려던 문제
- 오늘 완성한 핵심 시나리오
- 로컬 또는 배포 URL
- 실제 데이터 대신 사용한 더미 데이터
- 수업 후 가장 먼저 추가할 기능 하나

## AI 포털과 결과 공유

배포 URL이 있으면 https://mobi-aiax-portal.web.app/ 에 이름·URL·한 줄 설명을 참가자가 직접 남기게 한다. 배포하지 않았다면 로컬 화면이나 스크린샷과 한 줄 설명을 공유한다.

결과 공유는 한 사람당 2분 이내로 `무엇을 만들었는지 → 실제 동작 → 다음에 추가할 것` 순서로 진행하도록 안내한다.

## 수업 후 이어가기

`PROGRESS.md`와 `service-prd.md`를 기준으로 수업 후 과제 하나를 제안한다. DB, Gemini API, Codex, Skills 등은 웹 교재의 `더 가기` 자료를 각자 읽고 집에서 진행하게 한다.

## 하네스 정리

참가자에게 먼저 `수업 진행용 파일을 정리할까요? 서비스 코드와 작성한 문서는 그대로 남겨요.`라고 묻는다.

동의한 경우에만 `steps/`, `PROGRESS.md`와 수업 진행 규칙을 정리한다. `app/`, `data/`, `package.json`, 배포 설정, `draft.md`, `service-prd.md`와 참가자가 만든 산출물은 삭제하지 않는다. 동의하지 않으면 아무것도 삭제하지 않는다.
