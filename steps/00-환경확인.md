# 00 · 환경 확인

**목표**: 사전에 준비한 개발 환경과 수업용 프로젝트가 실제로 동작하는지만 확인한다.

## 먼저 읽기 전용으로 확인

다음 항목을 검사하고 `준비됨 / 확인 필요` 표로 보여준다.

1. 현재 프로젝트 폴더의 절대 경로
2. Claude Code가 이 폴더의 파일을 읽을 수 있는지
3. Node.js와 npm 버전
4. Git 설치 여부와 저장소 상태, 현재 프로젝트의 `git user.name`·`git user.email` 설정 여부
5. `package.json` 존재 여부
6. 의존성 설치 여부
7. `.env.local` 존재 여부와 `.gitignore` 제외 여부
8. 수업 장소의 현재 네트워크에서 `vercel whoami`가 실제로 응답하는지, 또는 `VERCEL_TOKEN` 항목이 존재하는지

시크릿의 실제 값은 읽거나 출력하지 않는다. 이 확인 단계에서는 파일 수정, 설치, 삭제, 배포, Git 커밋을 하지 않는다.

## 하나라도 준비되지 않았다면

- 안전하게 바로 해결할 수 있는 항목만 하나씩 처리한다.
- Git 사용자 정보가 없다면 참가자에게 사용할 이름과 이메일을 확인한 뒤 이 프로젝트에만 `git config user.name`, `git config user.email`을 설정한다. 전역 설정은 바꾸지 않는다.
- 새 프로그램 설치, 계정 권한, 토큰 발급 문제는 결과 표를 보여주며 코치를 부르게 한다.
- Vercel CLI가 설치되어 있어도 `vercel whoami`가 응답하지 않으면 통과로 표시하지 않는다. 로그인 만료·사내망 차단·통신 오류를 구분해 알려준다.
- 임의 파일 삭제, 기존 프로젝트 덮어쓰기, 토큰 재발급은 하지 않는다.

## 실행 확인

준비가 끝났다면 네가 `npm run dev`를 실행하고 표시된 실제 Local URL을 쉬운 말로 알려준다. 참가자에게 터미널을 열거나 명령을 직접 입력하게 하지 않는다. 참가자는 브라우저에서 `수업 준비 완료` 화면만 직접 확인한다.

**여러분이 직접 할 일**: 안내받은 Local URL을 브라우저에서 열어 준비 완료 화면을 확인한다.

**완료 신호**: 여러분이 로컬 화면을 확인하고 `됐어` 또는 `다음`이라고 말한다.

**PROGRESS 기록**: 로컬 확인 URL을 적고 00 단계를 완료한다.
